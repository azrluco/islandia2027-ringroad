# Islandia 2027 · Ring Road animada

Mapa visual animado del viaje a Islandia (7 jornadas).

## Publicación en GitHub Pages
1. Crea un repositorio público `islandia2027-ringroad`.
2. Sube `index.html` y `.nojekyll` a la raíz de la rama `main`.
3. En **Settings > Pages**, selecciona **Deploy from a branch**, rama `main`, carpeta `/(root)` y pulsa **Save**.
4. Abre la dirección publicada que aparecerá en Settings > Pages. Normalmente será `https://TU-USUARIO.github.io/islandia2027-ringroad/`.

Para actualizar: reemplaza `index.html` en la rama `main`. La URL se mantiene.

El mapa y la animación están incorporados en el HTML. Los enlaces a Google Maps requieren conexión.

**Aviso:** GitHub Pages publica el sitio de forma pública. No incluyas reservas, datos personales ni direcciones de alojamiento privadas sin protección adecuada.
